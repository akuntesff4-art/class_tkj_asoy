🌐 Tentang Website

Website ini adalah portal resmi CLASS QUESTERS TKJ A — tempat berkumpulnya semua informasi kelas: struktur pengurus, jadwal mata pelajaran, jadwal piket, kumpulan video kenangan, sampai link social media kelas. Tujuannya sederhana: biar semua anak kelas gampang cek info penting tanpa harus tanya sana-sini di grup chat.

Dibangun sebagai single-page app — semua halaman ada dalam satu dokumen, jadi pindah menu terasa instan dan music player nggak pernah berhenti gara-gara reload. Backend pakai Node.js + Express (data bisa diedit lewat admin panel), frontend HTML5, CSS3, dan JavaScript murni, lengkap dengan efek partikel, sound effect, dan animasi yang didesain supaya tetap ringan dibuka dari HP.

Node.js Express HTML5 CSS3 JavaScript Web Audio API
